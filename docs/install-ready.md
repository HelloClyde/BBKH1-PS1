# H1 PSX 即用安装包 v0.1.3

适用步步高 H1 / Y100（V1.41）。已包含 PSX 模拟器和 SCPH1001 BIOS，解压后放入游戏即可运行。

1. 将本包全部文件解压并合并到 H1 内置磁盘根目录。程序为 `A:\应用\程序\PSX.bda`，BIOS 为 `A:\PS1\bios.bin`。
2. 将自己的游戏镜像放在 SD 卡 `B:\PS1\`。多音轨游戏保留全部 BIN 文件，从 CUE 启动。
3. 从桌面打开 **PSX**，选择游戏；点击触屏可暂停、改按键、调音量或退出。

可先运行 `A:\PS1\H1TEST.exe` 检查安装。已有 BIOS 可跳过同名文件；本包不包含记忆卡、游戏镜像或 BBK 设备固件。

| 按键 | 操作 |
| --- | --- |
| 方向键 | PS1 方向键 |
| Z / X / C / V | × / □ / ○ / △ |
| A / S；Q / W | L1 / R1；L2 / R2 |
| Enter 或确认；空格 | Start；Select |
| 点击触屏；P / Esc / 返回 | 暂停菜单 |
