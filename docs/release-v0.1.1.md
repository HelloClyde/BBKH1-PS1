# H1 PS1 v0.1.1 预发布

点击触屏，或按 P/Esc/返回，打开与 H1 GBA 模拟器相同操作方式的暂停菜单。菜单包括继续、14 个 PS1 按钮映射、声音、显示、关于和退出；菜单内用方向键/确认/回车/Z 选择，返回/P 回上一级。

音量支持触摸滑条与左右键，提供静音、极速音频、插值与混响选项；显示页提供 GPU 跳帧、LCD 输出间隔和 FPS/CPU 频率显示。映射与设置按游戏分别保存，损坏或部分写入会优先保留上一份有效记录。关闭程序还原设备原音量和原频；菜单中的退出会同步记忆卡。

暂停发生在逻辑帧边界，客体 CPU/RAM 停止推进、PCM 停止并取消队列。打开菜单的触摸/抬笔与合成 Esc 不会误点菜单项，拖出按钮可取消，音量条持有触点直至抬笔。

确切编译 BDA 的主机 MIPS 服务模型检查涵盖菜单、实际输入映射、设置重开、CRC/短写回退、暂停/恢复及退出清理。本版按此前要求未调用 H1Debug、未安装到设备、没有新的 FF7/赛车物理帧率结论。408 MHz 仍是运行时配置，420 MHz 仍禁用。本版继续以预发布分发。

下载 BDA 放到 `A:\应用\程序\`，或解压 install ZIP 合并目录。旧记忆卡不由安装包覆盖。附完整固定依赖源码、Noto 字形 OFL 许可与 SHA256SUMS；不包含商业 BIOS、游戏或 BBK 固件。
