# H1 PSX v0.1.3 预发布

BDA 文件名改为 **PSX.bda**，H1 桌面标题和暂停菜单的应用名改为 **PSX**。下载地址及安装 ZIP 均使用新文件名，GitHub 仓库名继续使用 BBKH1-PS1。

重新生成 H1 风格图标：青蓝高光圆角底板、灰色光盘主机和手柄，以及清晰的 PSX 标识。底板外围透明，固定 SDK 打包四种 H1 原生图标资源；源 PNG、生成提示词和来源记录随完整源码提供。

升级时移除 `A:\应用\程序\H1PS1.bda`，将新文件复制到 `A:\应用\程序\PSX.bda`。游戏、BIOS、记忆卡与按游戏设置仍使用原有 PS1 目录，安装包不覆盖已有记忆卡。

本版保留触屏暂停、按键映射、音量、音质、显示设置、关于和退出功能，以及此前相同的模拟器优化和运行时 408 MHz 配置。编译后的确切 BDA 进行主机 MIPS/服务模型回归及图标解包检查；本轮按既有要求未调用 H1Debug、未安装到设备，也没有新的 FF7 或赛车真机性能结论。

发布包含 PSX.bda、安装 ZIP、完整固定依赖源码、构建清单及 SHA256SUMS.txt。SDK 仍固定为 067fe072477861dfc8949d7b1a55279fb92d2548；构建命令为 `python tools/build_release.py`。
