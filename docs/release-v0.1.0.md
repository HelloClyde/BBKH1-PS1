# H1 PS1 v0.1.0 预发布

H1/Y100 V1.41 原生 PS1 模拟器，加入两侧黑边 HUD：左上画面更新 FPS / 逻辑 FPS，右上实际 CPU MHz。启用 MIPS JIT、MXU1、VLC HLE、GPU 跳帧和可关闭的有损极速音频；默认尝试运行时 408 MHz，正常退出还原。420 MHz 已禁用。

此前非 HUD 的 408 MHz 开声诊断版本在 FF7 慢片头约 60.01 逻辑帧/秒、后段 60.00，两个窗口欠载 0，整轮欠载 2，正常退出。当前 HUD BDA 的启动、声音控制、退出、时钟恢复和 HUD 绘制通过主机 MIPS 服务模型验证；按用户要求未再使用 H1Debug 上机验证。本版以预发布分发，不代表全游戏或所有设备都满速。

下载 `H1PS1.bda` 放到 `A:\应用\程序\`，或解压 install ZIP 合并目录。`PS1/H1TEST.exe` 是原创自检程序。自己的 BIOS 可放到 `A:\PS1\bios.bin`；游戏可放内置盘或 SD 卡。Z/X/C/V 对应 ×/□/○/△，P 暂停，Esc/返回保存记忆卡并退出，T/H 调整音频。完整操作及依赖见 README。

附完整固定依赖源码包及 SHA256SUMS。BIOS、商业游戏、BBK 固件和个人存档不包含。现有记忆卡不会由安装包覆盖。
