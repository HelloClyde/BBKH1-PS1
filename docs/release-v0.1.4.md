# H1 PSX v0.1.4

新增 PSP 常用的 PS1 **EBOOT.PBP** 支持：可直接打开 PSX2PSP / popstation 的未加密单碟或多碟文件，无需先解压成 BIN。安装包已内置 BIOS，解压到 H1 内置盘，放入游戏即可开始。

- 支持 16 扇区一块的 raw Deflate 压缩及未压缩块，包含混合数据和 CDDA 音轨。
- 多碟 PBP 默认从第一张光盘启动；游戏要求换盘时，点击触屏，在暂停菜单选择“更换光盘”。最多支持八张，换盘保留当前游戏运行状态。
- 数据与 CDDA 分别缓存解压块，复用 zlib 状态，避免连续读取时反复解压；原 BIN/ISO/CUE 读取路径保留。
- 加密 PSN PBP、PSP 原生游戏及 2 GiB 及以上文件暂不支持，遇到不支持的文件会提示原因。
- 安装包包含同一份经发布者确认可再分发的 SCPH1001 BIOS、原创自检程序和来源记录，不包含商业游戏或 BBK 固件，不覆盖记忆卡。

验证覆盖确切 BDA 的主机 MIPS/服务模型：PBP 启动原创 ISO9660 自检光盘、触屏换盘并恢复、压缩/未压缩块、缓存与 CDDA、异常文件及资源释放；同时回归现有菜单、按键、音频和时钟。没有调用 H1Debug，没有新的真机帧率结论。SDK 仍固定为 `067fe072477861dfc8949d7b1a55279fb92d2548`。
